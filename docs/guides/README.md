# docs/guides 导航

`docs/guides/` 面向安装者和已有用户。此页只负责按任务路由，配置字段和运行行为以代码、示例配置和发行制品为准。

## 给 LLM 的快速索引

| 主题 | 直接入口 | 读取说明 |
| --- | --- | --- |
| 安装 | [installation.md](./installation.md) | 选择 Standalone Skill 或 Codex Plugin，并完成安装。 |
| 配置 | [configuration.md](./configuration.md) | 连接图片服务并设置模型、输出和资源限制。 |
| 迁移 | [migration.md](./migration.md) | 从 `v0.3.0` 或开发期 Plugin 显式迁移。 |
| 回滚 | [rollback.md](./rollback.md) | 恢复旧版 Skill 或固定 Plugin marketplace 版本。 |
| 故障排查 | [troubleshooting.md](./troubleshooting.md) | 识别依赖、配置、MCP 和宿主问题。 |

## 给人类的导航

第一次使用请从 [安装指南](./installation.md) 开始。已经安装但无法运行时，直接查看 [故障排查](./troubleshooting.md)。
