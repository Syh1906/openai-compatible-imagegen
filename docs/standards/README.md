# docs/standards 导航

`docs/standards/` 维护当前项目正式文档的写作规范。此页只负责把维护者路由到对应规则。

## 给 LLM 的快速索引

| 主题 | 直接入口 | 读取说明 |
| --- | --- | --- |
| 通用规则 | [通用文档规范.md](./通用文档规范.md) | 读取顺序、事实口径和 docs impact review。 |
| README 规范 | [README索引规范.md](./README索引规范.md) | 导航型与目录索引型 README。 |
| 长期说明 | [长期说明文档规范.md](./长期说明文档规范.md) | 项目总览、架构和维护边界。 |
| 用户指南 | [用户指南规范.md](./用户指南规范.md) | 安装、配置、迁移、回滚和故障排查。 |
| 项目画像 | [项目画像文档规范.md](./项目画像文档规范.md) | docs 治理画像的维护口径。 |
| 模板入口 | [../templates/README.md](../templates/README.md) | 当前项目认可的模板骨架。 |

## 给人类的导航

先读 [通用文档规范.md](./通用文档规范.md)，再按要维护的文档类型选择对应规范。
